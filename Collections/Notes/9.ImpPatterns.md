PART 10 — IMPORTANT PATTERNS FOR CODING ASSESSMENTS
38. Pattern 1: Frequency counting

Use when a problem asks:

How many times does each element appear?
Are two strings anagrams?
Which element occurs most frequently?
How many elements occur exactly k times?

Template:

HashMap<Integer, Integer> freq = new HashMap<>();

for (int num : nums) {
    freq.put(num, freq.getOrDefault(num, 0) + 1);
}
39. Pattern 2: Seen set

Use when a problem asks:

Does a duplicate exist?
Have we encountered this value before?
Are there two equal values?
Is a value already present?

Template:

HashSet<Integer> seen = new HashSet<>();

for (int num : nums) {

    if (seen.contains(num)) {
        // Handle duplicate
    }

    seen.add(num);
}
40. Pattern 3: Value-to-index map

Use when you need to find a matching value and know its earlier position.

Template:

HashMap<Integer, Integer> indexMap = new HashMap<>();

for (int i = 0; i < nums.length; i++) {

    int num = nums[i];

    indexMap.put(num, i);
}

This is particularly useful in Two Sum.

41. Pattern 4: Stack processing

Use when:

You must match opening and closing brackets.
You need the most recent unmatched element.
You need to process elements in reverse order.
You need a monotonic stack.

Template:

Deque<Integer> stack = new ArrayDeque<>();

for (int num : nums) {

    while (!stack.isEmpty() && /* condition */) {
        stack.pop();
    }

    stack.push(num);
}

The condition depends on the problem.

42. Pattern 5: Queue-based BFS

Use when exploring nodes level by level.

Template:

Queue<Integer> queue = new ArrayDeque<>();

queue.offer(start);

while (!queue.isEmpty()) {

    int node = queue.poll();

    // Process node

    // Add eligible neighbors
}

For graphs, mark nodes as visited when you enqueue them to avoid repeatedly adding the same nodes.

43. Pattern 6: Heap of size k

Use for top-K and kth-element problems.

Template:

PriorityQueue<Integer> minHeap = new PriorityQueue<>();

for (int num : nums) {

    minHeap.offer(num);

    if (minHeap.size() > k) {
        minHeap.poll();
    }
}

The final heap contains the k largest values, including duplicates.

44. Pattern 7: Linked-list pointer manipulation

Use when reversing, deleting, inserting, or rearranging nodes.

Template:

ListNode dummy = new ListNode(0);
dummy.next = head;

ListNode current = dummy;

while (current.next != null) {

    // Inspect or modify current.next

}

A dummy node often simplifies boundary cases.
