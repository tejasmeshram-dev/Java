PART 7 — PRIORITYQUEUE AND HEAPS
23. What is a heap?

A heap is a data structure that allows you to retrieve the minimum or maximum element efficiently.

Java implements a priority queue using a heap.

The most important distinction is:

A heap does not maintain a fully sorted sequence. It maintains the ordering required to identify the highest-priority element.

For a min-heap, the smallest element is at the top.

For a max-heap, the largest element is at the top.

Common applications
Kth largest element.
Kth smallest element.
Top K frequent elements.
Merge K sorted lists.
Dijkstra's shortest-path algorithm.
Scheduling by priority.
Maintaining the smallest or largest elements while processing a stream.
24. Min-heap in Java

Java's PriorityQueue is a min-heap by default.

import java.util.PriorityQueue;

PriorityQueue<Integer> minHeap = new PriorityQueue<>();
Example
PriorityQueue<Integer> minHeap = new PriorityQueue<>();

minHeap.offer(30);
minHeap.offer(10);
minHeap.offer(20);

System.out.println(minHeap.peek()); // 10

System.out.println(minHeap.poll()); // 10
System.out.println(minHeap.poll()); // 20
System.out.println(minHeap.poll()); // 30

Although the values were inserted in the order 30, 10, 20, removals occur in ascending order.

Important methods
Method	Purpose

poll()	Remove the smallest element
remove(value)	Remove a matching element

25. Creating a max-heap

For a max-heap, reverse the comparator.

PriorityQueue<Integer> maxHeap =
        new PriorityQueue<>((a, b) -> Integer.compare(b, a));

Example:

import java.util.PriorityQueue;

public class Main {
    public static void main(String[] args) {

        PriorityQueue<Integer> maxHeap =
                new PriorityQueue<>((a, b) -> Integer.compare(b, a));

        maxHeap.offer(10);
        maxHeap.offer(50);
        maxHeap.offer(30);

        System.out.println(maxHeap.poll()); // 50
        System.out.println(maxHeap.poll()); // 30
        System.out.println(maxHeap.poll()); // 10
    }
}
Why use Integer.compare() instead of subtraction?

You may see:

(a, b) -> b - a

Avoid this pattern when comparing integers that may be large.

Subtraction can overflow.

Use:

(a, b) -> Integer.compare(b, a)

This expresses the intended comparison safely.

Another option
PriorityQueue<Integer> maxHeap =
        new PriorityQueue<>(java.util.Collections.reverseOrder());

This also creates a max-heap for integers.

26. A common PriorityQueue mistake

Suppose you write:

PriorityQueue<Integer> pq = new PriorityQueue<>();

pq.offer(50);
pq.offer(10);
pq.offer(30);

System.out.println(pq);

Do not assume that the printed output will be:

[10, 30, 50]

A priority queue does not guarantee that iteration or printing will display all elements in sorted order.

The ordering guarantee applies to the element at the head and to repeated removals.

To retrieve elements in priority order:

while (!pq.isEmpty()) {
    System.out.println(pq.poll());
}

Remember that poll() modifies the queue.

If you need to preserve the original queue, copy it first:

PriorityQueue<Integer> copy = new PriorityQueue<>(pq);

while (!copy.isEmpty()) {
    System.out.println(copy.poll());
}
27. Solved problem: Kth largest element

Problem: Given an integer array and an integer k, return the kth largest element.

Example:

nums = [3, 2, 1, 5, 6, 4]
k = 2

Output:

5

The largest element is 6.

The second-largest is 5.

Approach: Maintain a min-heap of size k

The idea is:

Insert each number into a min-heap.
If the heap size exceeds k, remove its smallest element.
At the end, the heap contains the k largest elements.
Its smallest element is the kth largest overall.
Complete solution
import java.util.PriorityQueue;

class Solution {

    public int findKthLargest(int[] nums, int k) {

        PriorityQueue<Integer> minHeap = new PriorityQueue<>();

        for (int num : nums) {

            minHeap.offer(num);

            if (minHeap.size() > k) {
                minHeap.poll();
            }
        }

        return minHeap.peek();
    }
}
Dry run

Input:

[3, 2, 1, 5, 6, 4], k = 2
Number	Heap after processing, conceptually sorted	Action
3	[3]	Keep
2	[2, 3]	Keep
1	[2, 3]	Remove 1
5	[3, 5]	Remove 2
6	[5, 6]	Remove 3
4	[5, 6]	Remove 4

The smallest element remaining is 5.

Therefore, the answer is 5.

Complexity
Time: O(n log k).
Auxiliary space: O(k).
Important distinction: duplicates

This solution counts duplicate values as separate elements.

For example:

nums = [5, 5, 4, 3]
k = 2

The second-largest element is 5, not 4.

This is because the problem asks for the kth largest element, not the kth distinct largest value.

28. PriorityQueue with custom objects

You may eventually need to store objects rather than integers.

For example:

class Student {
    String name;
    int score;

    Student(String name, int score) {
        this.name = name;
        this.score = score;
    }
}

To create a priority queue that places higher scores first:

PriorityQueue<Student> pq =
        new PriorityQueue<>(
            (a, b) -> Integer.compare(b.score, a.score)
        );

Now you can insert students:

pq.offer(new Student("Aman", 80));
pq.offer(new Student("Priya", 95));
pq.offer(new Student("Rahul", 70));

The student with score 95 will be at the head.

For DSA problems, custom objects commonly appear in graph algorithms, scheduling, and problems involving pairs such as (distance, node).

Important: If two objects have equal priority, the queue does not guarantee their relative order unless your comparator explicitly defines a tie-breaker.
