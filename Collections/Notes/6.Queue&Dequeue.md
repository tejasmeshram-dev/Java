PART 6 — QUEUES AND DEQUES
19. What is a queue?

A queue follows FIFO: First In, First Out.

Imagine people waiting in a line.

The first person to join the line is served first.

Example:

Insert 10
Insert 20
Insert 30

The queue is:

Front -> 10, 20, 30 <- Rear

The first removal returns 10.

Applications

Queues appear in:

Breadth-first search.
Level-order tree traversal.
Graph traversal.
Shortest-path algorithms in unweighted graphs.
Task scheduling.
Simulation problems.
20. Implementing a queue in Java

Use:

import java.util.ArrayDeque;
import java.util.Queue;

Queue<Integer> queue = new ArrayDeque<>();
Essential methods
Method	Purpose
offer(value)	Add to the rear
poll()	Remove and return the front
peek()	Read the front without removing it
isEmpty()	Check whether empty
size()	Return the number of elements
clear()	Remove all elements
Example
import java.util.ArrayDeque;
import java.util.Queue;

public class Main {
    public static void main(String[] args) {

        Queue<Integer> queue = new ArrayDeque<>();

        queue.offer(10);
        queue.offer(20);
        queue.offer(30);

        System.out.println(queue.peek()); // 10

        System.out.println(queue.poll()); // 10
        System.out.println(queue.poll()); // 20

        System.out.println(queue.peek()); // 30
    }
}
Why use offer() instead of add()?

Both can insert elements.

However:

add() may throw an exception if insertion fails.
offer() returns false if insertion fails.

For ordinary ArrayDeque use, capacity usually grows automatically, so this distinction rarely affects DSA solutions.

Important: poll() versus remove()

When the queue is empty:

Method	Behavior
poll()	Returns null
remove()	Throws NoSuchElementException
peek()	Returns null
element()	Throws NoSuchElementException

This difference can help you avoid exceptions.

Remember that ArrayDeque does not permit null elements, so poll() returning null unambiguously indicates an empty queue.

21. What is a Deque?

A deque is a double-ended queue.

You can insert and remove elements from both ends.

Deque<Integer> deque = new ArrayDeque<>();
Important methods
Method	Purpose
addFirst(value)	Insert at the front
addLast(value)	Insert at the rear
removeFirst()	Remove the front
removeLast()	Remove the rear
peekFirst()	Examine the front
peekLast()	Examine the rear
offerFirst(value)	Attempt insertion at the front
offerLast(value)	Attempt insertion at the rear
pollFirst()	Remove front, returning null if empty
pollLast()	Remove rear, returning null if empty
Example
import java.util.ArrayDeque;
import java.util.Deque;

public class Main {
    public static void main(String[] args) {

        Deque<Integer> deque = new ArrayDeque<>();

        deque.addFirst(20);
        deque.addFirst(10);
        deque.addLast(30);

        System.out.println(deque); // [10, 20, 30]

        System.out.println(deque.removeFirst()); // 10
        System.out.println(deque.removeLast());  // 30

        System.out.println(deque.peekFirst()); // 20
    }
}
A very useful distinction

A Deque can function as both a stack and a queue.

As a stack:

stack.push(value);
stack.pop();
stack.peek();

As a queue:

queue.offer(value);
queue.poll();
queue.peek();

This is why Deque is particularly valuable in Java DSA.

22. Solved example: Reverse a string using a stack

Although Java provides convenient string-reversal alternatives, implementing reversal with a stack helps you understand LIFO.

import java.util.ArrayDeque;
import java.util.Deque;

public class Main {

    public static String reverse(String s) {

        Deque<Character> stack = new ArrayDeque<>();

        for (int i = 0; i < s.length(); i++) {
            stack.push(s.charAt(i));
        }

        StringBuilder result = new StringBuilder();

        while (!stack.isEmpty()) {
            result.append(stack.pop());
        }

        return result.toString();
    }

    public static void main(String[] args) {

        System.out.println(reverse("java"));
    }
}

Output:

avaj

Time complexity: O(n).

Auxiliary space complexity: O(n).

Important limitation: This simple implementation reverses UTF-16 char units. It is suitable for basic DSA exercises involving ordinary ASCII strings, but it is not a complete Unicode grapheme-reversal algorithm
