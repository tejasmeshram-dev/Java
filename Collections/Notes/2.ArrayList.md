PART 2 — ARRAYLIST
3. What is an ArrayList?

An ArrayList is a dynamically resizable list.

Unlike an ordinary array, it can grow or shrink as elements are added or removed.

Ordinary array
int[] nums = new int[3];

nums[0] = 10;
nums[1] = 20;
nums[2] = 30;

The array has a fixed length of three.

ArrayList
ArrayList<Integer> nums = new ArrayList<>();

nums.add(10);
nums.add(20);
nums.add(30);
nums.add(40);

The list can grow as needed.

Declaration syntax
ArrayList<Integer> list = new ArrayList<>();

Breaking this down:

ArrayList: The implementation.
Integer: The type of elements.
list: The variable.
new ArrayList<>(): Creates a new, initially empty list.

You can also use the List interface:

List<Integer> list = new ArrayList<>();

This is often preferable because it allows you to change the implementation without changing the variable's declared type.

For example, you might later use a different implementation of List.

4. Essential ArrayList methods

Learn these methods first.

Method	Purpose	Example
add(value)	Append an element	list.add(10);
add(index, value)	Insert at an index	list.add(1, 50);
get(index)	Read an element	list.get(0)
set(index, value)	Replace an element	list.set(0, 99);
remove(index)	Remove by index	list.remove(0);
remove(Object)	Remove a matching value	list.remove(Integer.valueOf(20));
size()	Return the number of elements	list.size()
isEmpty()	Check whether the list is empty	list.isEmpty()
contains(value)	Check whether a value exists	list.contains(10)
indexOf(value)	Find the first matching index	list.indexOf(20)
lastIndexOf(value)	Find the last matching index	list.lastIndexOf(20)
clear()	Remove every element	list.clear()
toArray()	Convert to an array	list.toArray()
Example 1: Adding elements
import java.util.ArrayList;

public class Main {
    public static void main(String[] args) {

        ArrayList<Integer> list = new ArrayList<>();

        list.add(10);
        list.add(20);
        list.add(30);

        System.out.println(list);
    }
}

Output:

[10, 20, 30]
Example 2: Accessing elements
ArrayList<Integer> list = new ArrayList<>();

list.add(10);
list.add(20);
list.add(30);

System.out.println(list.get(0)); // 10
System.out.println(list.get(1)); // 20
System.out.println(list.get(2)); // 30

Remember that Java uses zero-based indexing.

For a list containing n elements, valid indexes are:

0 through n - 1
Example 3: Updating elements
ArrayList<Integer> list = new ArrayList<>();

list.add(10);
list.add(20);
list.add(30);

list.set(1, 99);

System.out.println(list);

Output:

[10, 99, 30]

set() replaces an existing element. It does not insert a new element.

Compare:

list.set(1, 99);    // Replace the element at index 1
list.add(1, 99);    // Insert at index 1 and shift later elements

This distinction is frequently tested in programming exercises.

Example 4: Removing elements
ArrayList<Integer> list = new ArrayList<>();

list.add(10);
list.add(20);
list.add(30);

list.remove(1);

System.out.println(list);

Output:

[10, 30]

The element at index 1 was removed.

Important Java trap: remove() overloads

Consider:

ArrayList<Integer> list = new ArrayList<>();

list.add(10);
list.add(20);
list.add(30);

list.remove(1);

This removes the element at index 1, meaning 20.

But:

list.remove(Integer.valueOf(20));

removes the matching value 20.

Why?

Because ArrayList<Integer> has two relevant overloads:

remove(int index)
remove(Object value)

When you pass an int, Java chooses the index-based overload.

Example 5: Checking for a value
ArrayList<Integer> list = new ArrayList<>();

list.add(10);
list.add(20);
list.add(30);

System.out.println(list.contains(20)); // true
System.out.println(list.contains(50)); // false

This is useful, but remember that checking membership in an ArrayList generally takes linear time.

If you repeatedly need membership checks, a HashSet may be a better choice.

5. Looping through an ArrayList
Method A: Traditional for loop
for (int i = 0; i < list.size(); i++) {
    System.out.println(list.get(i));
}

Use this when you need the index.

Method B: Enhanced for loop
for (int value : list) {
    System.out.println(value);
}

This is useful when you only need the values.

Method C: forEach with a lambda
list.forEach(value -> System.out.println(value));

This is useful Java syntax to recognize, although traditional loops are perfectly suitable for most DSA solutions.

Important mistake

Do not modify the size of an ArrayList while iterating through it with an enhanced for loop.

For example, this can throw ConcurrentModificationException:

for (int value : list) {
    if (value == 20) {
        list.remove(Integer.valueOf(value));
    }
}

Safer alternatives include:

Using an iterator:

import java.util.ArrayList;
import java.util.Iterator;

ArrayList<Integer> list = new ArrayList<>();

list.add(10);
list.add(20);
list.add(30);

Iterator<Integer> iterator = list.iterator();

while (iterator.hasNext()) {
    int value = iterator.next();

    if (value == 20) {
        iterator.remove();
    }
}

Or using removeIf():

list.removeIf(value -> value == 20);

For ordinary DSA problems, you can often avoid this issue by building a new result list instead.

6. ArrayList time complexity

Let n be the number of elements.

Operation	Typical complexity
get(index)	O(1)
set(index, value)	O(1)
add(value)	Amortized O(1)
add(index, value)	O(n)
remove(index)	O(n) in general
contains(value)	O(n)
indexOf(value)	O(n)
size()	O(1)

Why is appending amortized O(1)?

An ArrayList uses a resizable backing array. Most additions simply place an element at the end. Occasionally, the backing array must grow and existing elements must be copied.

Across many additions, the average cost per addition remains constant.

When should you use ArrayList?

Use it when you need:

A dynamically sized collection.
Fast indexed access.
A list of results.
A sequence of elements that changes in size.
A convenient result type for backtracking or graph algorithms.
