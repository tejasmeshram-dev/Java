PART 4 — HASHSET
12. What is a HashSet?

A HashSet stores unique elements.

Unlike a HashMap, it does not store a separate value for each key.

HashSet<Integer> set = new HashSet<>();

set.add(10);
set.add(20);
set.add(10);

The set contains only:

10, 20

The duplicate insertion does not create another element.

Declaration
HashSet<Integer> set = new HashSet<>();

Or:

Set<Integer> set = new HashSet<>();

The second form uses the Set interface and is often preferable.

13. Essential HashSet methods
Method	Purpose
add(value)	Add an element if absent
contains(value)	Check whether an element exists
remove(value)	Remove an element
size()	Return the number of elements
isEmpty()	Check whether the set is empty
clear()	Remove all elements
addAll(collection)	Add elements from another collection
retainAll(collection)	Keep only common elements
removeAll(collection)	Remove elements present in another collection
Example
import java.util.HashSet;

public class Main {
    public static void main(String[] args) {

        HashSet<Integer> set = new HashSet<>();

        set.add(10);
        set.add(20);
        set.add(30);
        set.add(10);

        System.out.println(set.size());       // 3
        System.out.println(set.contains(20)); // true
        System.out.println(set.contains(50)); // false

        set.remove(20);

        System.out.println(set.size());       // 2
    }
}
Important characteristics
A HashSet does not guarantee iteration order.
It stores unique elements according to equals() and hashCode().
It permits one null element.
Basic operations generally take expected O(1) time under normal hashing conditions.
14. Solved problem: Contains Duplicate

Problem: Given an integer array, return true if any value appears at least twice.

Example:

Input:  [1, 2, 3, 1]
Output: true
Approach

Maintain a set of values already encountered.

For every number:

Check whether it already exists in the set.
If it exists, return true.
Otherwise, add it.
If the loop finishes, return false.
Complete code
import java.util.HashSet;

class Solution {

    public boolean containsDuplicate(int[] nums) {

        HashSet<Integer> seen = new HashSet<>();

        for (int num : nums) {

            if (seen.contains(num)) {
                return true;
            }

            seen.add(num);
        }

        return false;
    }
}
Dry run

Input:

[1, 2, 3, 1]
Current number	Set before processing	Result
1	{}	Add 1
2	{1}	Add 2
3	{1, 2}	Add 3
1	{1, 2, 3}	Duplicate found

The algorithm returns true immediately.

A shorter implementation

You can also write:

class Solution {

    public boolean containsDuplicate(int[] nums) {

        HashSet<Integer> seen = new HashSet<>();

        for (int num : nums) {
            if (!seen.add(num)) {
                return true;
            }
        }

        return false;
    }
}

Why does this work?

set.add(num) returns:

true if the element was newly added.
false if the element was already present.

This is a useful Java technique.

Complexity
Time: Expected O(n).
Space: O(n).
15. HashSet versus HashMap

This distinction should become automatic.

Requirement	Choose
Check whether a value exists	HashSet
Detect duplicates	HashSet
Count occurrences	HashMap
Map a number to an index	HashMap
Map a character to a frequency	HashMap
Track previously seen values without additional information	HashSet
Associate each value with some data	HashMap

Interview tip: Before writing code, ask yourself: "Do I only need to know whether something exists, or do I need to remember information about it?"

If existence alone is enough, a set is often the natural choice.
