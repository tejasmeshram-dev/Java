PART 3 — HASHMAP
7. What is a HashMap?

A HashMap stores key-value pairs.

For example:

Key	Value
"apple"	3
"banana"	5
"orange"	2

You could interpret this as a mapping between fruit names and their quantities.

In Java:

HashMap<String, Integer> quantities = new HashMap<>();

quantities.put("apple", 3);
quantities.put("banana", 5);
quantities.put("orange", 2);

The key identifies an entry, and the value stores the associated information.

In DSA, HashMap is particularly important for:

Frequency counting.
Detecting duplicates.
Two Sum.
Grouping anagrams.
Sliding-window problems.
Prefix sums.
Graph adjacency structures.
Caching previously computed results.

You will encounter it repeatedly throughout NeetCode.

8. Declaring a HashMap
HashMap<Integer, Integer> map = new HashMap<>();

The first type represents the key.

The second type represents the value.

For example:

HashMap<String, Integer> scores = new HashMap<>();

Here, keys are strings and values are integers.

Another example:

HashMap<Integer, String> students = new HashMap<>();

students.put(101, "Rahul");
students.put(102, "Priya");
students.put(103, "Aman");

Now each student ID maps to a name.

Important rule

Keys are unique, but values do not need to be unique.

HashMap<String, Integer> map = new HashMap<>();

map.put("A", 10);
map.put("B", 20);
map.put("A", 30);

The final map contains:

A -> 30
B -> 20

The second insertion for key "A" replaces its previous value.

It does not create a second "A" entry.

9. Essential HashMap methods
Method	Purpose
put(key, value)	Insert or update an entry
get(key)	Retrieve a value
getOrDefault(key, defaultValue)	Return a value or a fallback
containsKey(key)	Check whether a key exists
containsValue(value)	Check whether a value exists
remove(key)	Remove an entry
putIfAbsent(key, value)	Insert only if the key is absent or mapped to null
keySet()	Obtain the set of keys
values()	Obtain the collection of values
entrySet()	Obtain key-value entries
size()	Return the number of entries
isEmpty()	Check whether the map is empty
clear()	Remove all entries
merge(key, value, function)	Insert or combine a mapping
computeIfAbsent(key, function)	Compute a value when needed

Let's understand the most useful ones.

A. put()
HashMap<Integer, String> map = new HashMap<>();

map.put(1, "Apple");
map.put(2, "Banana");

map.put(1, "Orange");

System.out.println(map.get(1));

Output:

Orange
B. get()
HashMap<Integer, String> map = new HashMap<>();

map.put(1, "Apple");

System.out.println(map.get(1)); // Apple
System.out.println(map.get(2)); // null

A missing key normally returns null.

This means you must be careful when retrieving values.

For example:

Integer count = map.get(100);

If key 100 is missing, count becomes null.

Attempting this can cause a NullPointerException:

int value = map.get(100);

Java attempts to unbox the null value into an int.

C. getOrDefault()

This is one of the most important methods for DSA.

HashMap<Integer, Integer> map = new HashMap<>();

map.put(1, 10);

System.out.println(map.getOrDefault(1, 0)); // 10
System.out.println(map.getOrDefault(2, 0)); // 0

The method returns the mapped value when available, or the specified default otherwise.

However, a subtle distinction matters: If a key exists and is explicitly mapped to null, getOrDefault() returns null, not the default value.

D. containsKey()
HashMap<Integer, String> map = new HashMap<>();

map.put(10, "A");

System.out.println(map.containsKey(10)); // true
System.out.println(map.containsKey(20)); // false

Use this when the existence of a key matters independently of its value.

E. remove()
HashMap<Integer, String> map = new HashMap<>();

map.put(1, "Apple");
map.put(2, "Banana");

map.remove(1);

The entry with key 1 is removed.

F. keySet()
for (Integer key : map.keySet()) {
    System.out.println(key);
}

This iterates through the keys.

G. values()
for (String value : map.values()) {
    System.out.println(value);
}

This iterates through the values.

H. entrySet()

When you need both keys and values, this is often the clearest option.

for (Map.Entry<Integer, String> entry : map.entrySet()) {

    System.out.println(entry.getKey());
    System.out.println(entry.getValue());
}

Make sure you import:

import java.util.Map;
10. The most important HashMap pattern: frequency counting

Suppose you are given:

int[] nums = {1, 2, 2, 3, 3, 3};

You want to count how often each number appears.

The desired result is:

1 -> 1
2 -> 2
3 -> 3
Step 1: Create a map
HashMap<Integer, Integer> freq = new HashMap<>();

The number is the key.

Its frequency is the value.

Step 2: Iterate through the array
for (int num : nums) {
    freq.put(num, freq.getOrDefault(num, 0) + 1);
}
Step 3: Understand what happens

When num = 1:

freq.getOrDefault(1, 0)

returns 0.

Therefore:

freq.put(1, 1);

When num = 2 appears for the first time:

freq.getOrDefault(2, 0)

returns 0.

Therefore:

freq.put(2, 1);

When num = 2 appears again:

freq.getOrDefault(2, 0)

returns 1.

Therefore:

freq.put(2, 2);

The same process continues for every element.

Complete solved example
import java.util.HashMap;

public class Main {
    public static void main(String[] args) {

        int[] nums = {1, 2, 2, 3, 3, 3};

        HashMap<Integer, Integer> freq = new HashMap<>();

        for (int num : nums) {
            freq.put(num, freq.getOrDefault(num, 0) + 1);
        }

        System.out.println(freq);
    }
}

Possible output:

{1=1, 2=2, 3=3}

The display order of a HashMap is not guaranteed.

Time complexity

If the array contains n elements, frequency counting takes expected O(n) time.

The map stores at most n distinct keys, so its auxiliary space complexity is O(n).

11. More frequency-counting patterns
Count characters in a string
import java.util.HashMap;

public class Main {
    public static void main(String[] args) {

        String s = "banana";

        HashMap<Character, Integer> freq = new HashMap<>();

        for (int i = 0; i < s.length(); i++) {

            char ch = s.charAt(i);

            freq.put(ch, freq.getOrDefault(ch, 0) + 1);
        }

        System.out.println(freq);
    }
}

Expected mappings:

b -> 1
a -> 3
n -> 2
Count words
String[] words = {"java", "python", "java", "c++"};

HashMap<String, Integer> freq = new HashMap<>();

for (String word : words) {
    freq.put(word, freq.getOrDefault(word, 0) + 1);
}

Result:

java -> 2
python -> 1
c++ -> 1
Using merge()

An alternative is:

for (int num : nums) {
    freq.merge(num, 1, Integer::sum);
}

This means:

If the key is absent, insert 1.
Otherwise, combine the existing value with 1 using integer addition.

Both patterns are useful.

For beginners, I recommend mastering getOrDefault() first because it makes the frequency update especially easy to understand.
