PART 5 — STACKS
16. What is a stack?

A stack follows LIFO: Last In, First Out.

Imagine a stack of plates.

The last plate placed on top is the first plate you remove.

Example:

Push 10
Push 20
Push 30

The stack looks like:

Top -> 30
       20
       10

The next removal returns 30.

Then 20.

Then 10.

Common applications

Stacks appear in:

Valid Parentheses.
Reverse operations.
Expression evaluation.
Monotonic stack problems.
Next Greater Element.
Daily Temperatures.
Tree traversal.
Depth-first search.
Undo functionality.
Backtracking.
17. How to implement a stack in Java

Java has a legacy Stack class, but for modern DSA code, Deque backed by ArrayDeque is generally preferred.

import java.util.ArrayDeque;
import java.util.Deque;

Deque<Integer> stack = new ArrayDeque<>();
Essential methods
Method	Purpose
push(value)	Add to the top
pop()	Remove and return the top
peek()	Read the top without removing it
isEmpty()	Check whether the stack is empty
size()	Return the number of elements
clear()	Remove all elements
Example
import java.util.ArrayDeque;
import java.util.Deque;

public class Main {
    public static void main(String[] args) {

        Deque<Integer> stack = new ArrayDeque<>();

        stack.push(10);
        stack.push(20);
        stack.push(30);

        System.out.println(stack.peek()); // 30

        System.out.println(stack.pop());  // 30
        System.out.println(stack.pop());  // 20

        System.out.println(stack.peek()); // 10
    }
}
The difference between peek() and pop()
stack.peek();

Returns the top element without removing it.

stack.pop();

Removes and returns the top element.

If the stack is empty, peek() returns null with an ArrayDeque, whereas pop() throws NoSuchElementException.

Therefore, if the stack might be empty, check:

if (!stack.isEmpty()) {
    int top = stack.pop();
}
Complexity

For an ArrayDeque used as a stack:

Operation	Typical complexity
push()	Amortized O(1)
pop()	O(1)
peek()	O(1)
isEmpty()	O(1)
18. Solved problem: Valid Parentheses

Problem: Given a string containing (), {}, and [], determine whether the brackets are valid.

Examples:

Input:  "()"
Output: true
Input:  "()[]{}"
Output: true
Input:  "(]"
Output: false
Input:  "([)]"
Output: false
The logic

When you encounter an opening bracket, remember it.

When you encounter a closing bracket:

There must be a corresponding opening bracket.
The most recent unmatched opening bracket must match it.
Remove that opening bracket from the stack.

At the end, the stack must be empty.

Why use a stack?

Consider:

([{}])

The brackets must close in reverse order of opening.

This is exactly what LIFO handles.

Complete solution
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {

    public boolean isValid(String s) {

        Deque<Character> stack = new ArrayDeque<>();

        for (int i = 0; i < s.length(); i++) {

            char ch = s.charAt(i);

            if (ch == '(' || ch == '[' || ch == '{') {

                stack.push(ch);

            } else {

                if (stack.isEmpty()) {
                    return false;
                }

                char top = stack.pop();

                if (ch == ')' && top != '(') {
                    return false;
                }

                if (ch == ']' && top != '[') {
                    return false;
                }

                if (ch == '}' && top != '{') {
                    return false;
                }
            }
        }

        return stack.isEmpty();
    }
}
Dry run

Input:

"([])"
Character	Operation	Stack
(	Push	(
[	Push	[(] conceptually: [ is now on top of (
]	Pop and match [	(
)	Pop and match (	Empty

The stack is empty at the end, so the answer is true.

Important edge cases
Input	Expected result	Reason
""	true	No unmatched brackets
"("	false	Opening bracket remains
")"	false	Closing bracket without an opener
"()"	true	Correct pair
"(]"	false	Mismatched pair
"([)]"	false	Incorrect nesting
"{[]}"	true	Correct nesting
Complexity
Time: O(n).
Space: O(n) in the worst case.

Key lesson: When a problem requires the most recent unmatched item, a stack should be one of your first considerations.
