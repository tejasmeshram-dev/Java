Operators

Operators allow you to perform calculations, compare values, and combine conditions.

4.1 Arithmetic operators
Operator	Meaning	Example
+	Addition	5 + 2 → 7
-	Subtraction	5 - 2 → 3
*	Multiplication	5 * 2 → 10
/	Division	5 / 2 → 2
%	Remainder	5 % 2 → 1

The remainder operator is particularly useful.

Example: determine whether a number is even.

int n = 8;

if (n % 2 == 0) {
    System.out.println("Even");
} else {
    System.out.println("Odd");
}

Output:

Even

An integer has remainder zero when divided by two if it is even.

4.2 Comparison operators
Operator	Meaning
==	Equal to
!=	Not equal to
>	Greater than
<	Less than
>=	Greater than or equal to
<=	Less than or equal to

Example:

int age = 20;

System.out.println(age >= 18);

Output:

true

Comparison expressions generally produce a boolean result.

4.3 Logical operators
Operator	Meaning
&&	Logical AND
||	Logical OR
!	Logical NOT

Example:

int age = 20;
boolean hasID = true;

if (age >= 18 && hasID) {
    System.out.println("Allowed");
}

Output:

Allowed

Both conditions must be true for && to produce true.

Short-circuit evaluation

Java's && and || operators can skip evaluating the second expression.

Consider:

String s = null;

if (s != null && s.length() > 0) {
    System.out.println("Not empty");
}

This is safe.

If s != null is false, Java does not evaluate s.length() > 0.

But replacing && with & would not provide this short-circuit behavior for boolean expressions.

4.4 Increment and decrement
int x = 5;

x++;

System.out.println(x);

Output:

6

Likewise:

int x = 5;

x--;

System.out.println(x);

Output:

4

Be careful with the difference between prefix and postfix expressions:

int x = 5;

System.out.println(x++);
System.out.println(x);

Output:

5
6

The postfix expression x++ evaluates to the old value and then increments x.

With prefix increment:

int x = 5;

System.out.println(++x);

Output:

6

For now, prefer simple increments on their own lines when writing DSA code. They are easier to reason about.

4.5 Compound assignment
int x = 10;

x += 5;  // x = x + 5
x -= 2;  // x = x - 2
x *= 3;  // x = x * 3
x /= 2;  // x = x / 2

These operators are common in loops and calculations.
