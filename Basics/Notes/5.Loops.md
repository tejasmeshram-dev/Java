## Loops

**Loops repeat code.**

### 1. The for loop

Syntax:
```
for (initialization; condition; update) {
    // Repeated code
}
```
Example:
```
for (int i = 0; i < 5; i++) {
    System.out.println(i);
}
```
Output:
```
0
1
2
3
4
```
Understand the three components:

- int i = 0;  // Initialization
- i < 5;      // Condition
- i++;        // Update

The loop continues while the condition is true.

When i becomes 5, the condition fails, and the loop terminates.

<br>

**NOTE: Critical: < versus <=**

Consider:
```
int[] nums = {10, 20, 30};
for (int i = 0; i < nums.length; i++) {
    System.out.println(nums[i]);
}
```
Output:
```
10
20
30
```
The array length is 3, and the valid indices are: 0, 1, 2

The correct condition is: i < nums.length
This is incorrect for ordinary array traversal: i <= nums.length
When i becomes 3, nums[3] is outside the array, resulting in an ArrayIndexOutOfBoundsException.
This boundary distinction is one of the most important things to master before beginning binary search.

<br>

### 2. The while loop

A while loop repeats as long as its condition remains true.
```
int x = 5;
while (x > 0) {
    System.out.println(x);
    x--;
}
```
Output:
```
5
4
3
2
1
```
Notice that x-- changes the condition's value.
If you forget the update, you may accidentally create an infinite loop.

<br>

### 3. The do-while loop

A do-while loop executes its body at least once.
```
int x = 5;
do {
    System.out.println(x);
    x--;
} while (x > 0);
```
The main difference is that the condition is checked after the body executes.

<br>

### 4. Enhanced for loop

This is especially useful when you need each element of an array.
```
int[] nums = {10, 20, 30};
for (int num : nums) {
    System.out.println(num);
}
```
Output:
```
10
20
30
```
Here, num receives the value of each element in sequence.

<br>

**Standard loop vs. Enhanced loop**

- Use a standard loop when you need the index:
```
for (int i = 0; i < nums.length; i++) {
    System.out.println(i + ": " + nums[i]);
}
```
- Use an enhanced loop when you only need the values:
```
for (int num : nums) {
    System.out.println(num);
}
```


**Important: assigning a new value to the enhanced-loop variable does not replace the corresponding array element.**

```
int[] nums = {1, 2, 3};
for (int num : nums) {
    num = 100;
}
```
The array remains: [1, 2, 3]
To modify array elements, use an index-based loop.

<br>

### 5. break and continue

**A. break exits the nearest enclosing loop.**
```
for (int i = 0; i < 10; i++) {
    if (i == 5) {
        break;
    }
    System.out.println(i);
}
```
Output:
```
0
1
2
3
4
```

<br>

**B. continue skips the remaining body for the current iteration.**
```
for (int i = 0; i < 5; i++) {
    if (i == 2) {
        continue;
    }
    System.out.println(i);
}
```
Output:
```
0
1
3
4
```

<br>

### 6. Common loop patterns

1. Count from zero:

```
for (int i = 0; i < n; i++) {
    // Work
}
```

2. Traverse an array:

```
for (int i = 0; i < nums.length; i++) {
    // Work with nums[i]
}
```

3. Traverse backwards:

```
for (int i = nums.length - 1; i >= 0; i--) {
    System.out.println(nums[i]);
}
```

4. Accumulate a sum:

```
int sum = 0;
for (int num : nums) {
    sum += num;
}
```

5. Count matching elements:

```
int count = 0;
for (int num : nums) {
    if (num > 10) {
        count++;
    }
}
```
