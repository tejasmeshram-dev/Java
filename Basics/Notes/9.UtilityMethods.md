## Essential Java Utility Methods

### 1. The Math class

You can use these static methods without creating a Math object.

|Method	|Example	|Result |
|---  |---  |---  |
|Math.max(a, b)	|Math.max(5, 9)  |9  |
|Math.min(a, b)	|Math.min(5, 9)  |5  |
|Math.abs(x)	|Math.abs(-10)  |10  |
|Math.sqrt(x)	|Math.sqrt(25)  |5.0  |
|Math.pow(a, b)	|Math.pow(2, 3) |8.0  |  

Example:
```
int a = 10;
int b = 20;
int max = Math.max(a, b);
int min = Math.min(a, b);
System.out.println(max);
System.out.println(min);
```
Output:
```
20
10
```
Remember that Math.pow() returns a double. For integer exponentiation, you may need a different approach depending on the problem's requirements.

<br>

### 2. The Arrays class

Import it with: `import java.util.Arrays;`

**Common Methods**

- `Arrays.sort(nums);`
- `Arrays.toString(nums);`
- `Arrays.equals(a, b);`
- `Arrays.fill(nums, 0);`
- `Arrays.copyOf(nums, nums.length);`

Example:
```
int[] nums = {5, 2, 9, 1};
Arrays.sort(nums);
System.out.println(Arrays.toString(nums));
```
Output:  `[1, 2, 5, 9]`

Note that Arrays.sort(nums) modifies the original array.

<br>

### 3. Basic type conversion

Java sometimes converts values automatically.
```
int x = 10;
double y = x;
System.out.println(y);
```
Output: `10.0`

This is a widening conversion from int to double.

<br>

The reverse may require an explicit cast:
```
double x = 10.8;
int y = (int) x;
System.out.println(y);
```
Output:  `10`

The fractional part is discarded. It is not rounded.

<br>

If you need rounding: `long rounded = Math.round(10.8);`

Result:  `11`
