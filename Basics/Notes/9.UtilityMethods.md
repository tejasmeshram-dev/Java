## Essential Java Utility Methods

### 1. The Math class

You can use these static methods without creating a Math object.

| Method or Constant | Purpose                     | Example            | Result                  |
| ------------------ | --------------------------- | ------------------ | ----------------------- |
| `Math.max(a, b)`   | Returns the larger of the two numbers               | `Math.max(5, 9)`  `Math.max(-5,-2)` | `9` `-2`                     |
| `Math.min(a, b)`   | Returns the smaller of the two numbers               | `Math.min(5, 9)`  `Math.max(-5,-2)` | `5` `-5`                     |
| `Math.abs(x)`      | Returns the absolute value of a number, removing its negative sign when applicable.              | `Math.abs(-8)`  `Math.abs(25)` `Math.abs(-3.5)`   | `8` `25` `3.5`                    |
| `Math.sqrt(x)`     | Returns the square root of a number as a double                 | `Math.sqrt(49)` `Math.sqrt(2)`    | `7.0` `1.4142135623730951`                   |
| `Math.pow(a, b)`   | Raises a to the power of b and returns a double                       | `Math.pow(2, 4)` `Math.pow(10, 0)`   | `16.0` `1.0`                  |

<br>
  - Math.pow() returns a double, even when the result is a whole number. For example: ` double result = Math.pow(2, 3); ` gives `8.0`.
  
  - If you need an integer result and know it is within the int range, you can cast it:
  ```
  int result = (int) Math.pow(2, 3);
  System.out.println(result);
  ```
  Output: ` 8 `

<br>

### 2. The Arrays class

Import it with: `import java.util.Arrays;`

**Common Methods**

<br>

A. Arrays.sort(nums);

  - Sorts the array in ascending order (smallest to largest).
  - Arrays.sort() changes the original array. It does not create a new one.
  ```
  int[] nums = {5, 2, 8, 1, 3};
  Arrays.sort(nums);
  System.out.println(Arrays.toString(nums));
  ```
  Output: `[1, 2, 3, 5, 8]`

<br>

B. Arrays.toString(nums);

  - Converts an array into a readable string representation so you can print its elements.
  - Arrays.toString() does not modify the original array.
  ```
  int[] nums = {10, 20, 30};
  System.out.println(Arrays.toString(nums));
  ```
  Output: `[10, 20, 30]`
  
<br>

C. Arrays.equals(a, b);

  - Checks whether two arrays have the same elements in the same order. Returns true if they match and false otherwise.
  - For arrays, use Arrays.equals(a, b) to compare their contents.
  ```
  int[] a = {1, 2, 3};
  int[] b = {1, 2, 3};
  int[] c = {3, 2, 1};
  System.out.println(Arrays.equals(a, b));
  System.out.println(Arrays.equals(a, c));
  ```
  Output: ```
          true
          false
          ```
  The second result is false because {1, 2, 3} and {3, 2, 1} contain the same values, but their elements are in different orders.
  
 <br>

D. Arrays.fill(nums, 0);

  - Fills every element of the array with the specified value.
  - Arrays.fill() modifies the original array.
  ```
  int[] nums = {5, 10, 15, 20};
  Arrays.fill(nums, 0);
  System.out.println(Arrays.toString(nums));
  ```
  Output: `[0, 0, 0, 0]`
  
  - You can fill the array with any appropriate value. For example:
  ```
  int[] nums = new int[5];
  Arrays.fill(nums, 7);
  System.out.println(Arrays.toString(nums));
  ```
  Output: `[7, 7, 7, 7, 7]`

<br>

E. Arrays.copyOf(nums, nums.length);

  - Creates a new array by copying elements from the original array.
  - The second argument specifies the length of the new array.
  ```
  int[] nums = {10, 20, 30};
  int[] copy = Arrays.copyOf(nums, nums.length);
  System.out.println(Arrays.toString(nums));
  System.out.println(Arrays.toString(copy));
  ```
  Output: ```
          [10, 20, 30]
          [10, 20, 30]
          ```
  Here, nums.length is 3, so the new array contains three elements.
  
  <br>
  
  **Important: You can change the new array independently. Changing copy does not change nums.**
  ```
  int[] nums = {10, 20, 30};
  int[] copy = Arrays.copyOf(nums, nums.length);
  copy[0] = 99;
  System.out.println(Arrays.toString(nums));
  System.out.println(Arrays.toString(copy));
  ```
  Output: ```
          [10, 20, 30]
          [99, 20, 30]
          ```
  
  **Important: You can make the length of new array longer and shorter.**
  
  a. New array is longer:
  ```
  int[] nums = {10, 20, 30};
  int[] copy = Arrays.copyOf(nums, 5);
  System.out.println(Arrays.toString(copy));
  ```
  Output: ` [10, 20, 30, 0, 0] `
  The additional elements are initialized to 0 because this is an int[].
  
  b. New array is shorter:
  ```
  int[] nums = {10, 20, 30, 40};
  int[] copy = Arrays.copyOf(nums, 2);
  System.out.println(Arrays.toString(copy));
  ```
  Output: ` [10, 20] `
  Only the first two elements are copied

### 3. Basic type conversion

Java sometimes converts values automatically.
```
int x = 10;
double y = x;
System.out.println(y);
```
Output: `10.0`

This is a widening conversion from int to double.

<br>

The reverse may require an explicit cast:
```
double x = 10.8;
int y = (int) x;
System.out.println(y);
```
Output:  `10`

The fractional part is discarded. It is not rounded. Because rounding will result in O/P `11` from `long rounded = Math.round(10.8);`

### 4. DSA Methods

When calculating the number of groups, batches, or pages needed, one might need ceiling division rather than ordinary integer division. 

For positive integers, you can calculate it as:
```
int items = 10;
int capacity = 3;
int groups = (items + capacity - 1) / capacity;
System.out.println(groups);
```
Output: ` 4 `

  - Why? Ten items require four groups if each group can hold three items.
  - This formula avoids floating-point calculations and is useful in coding assessments. It assumes capacity > 0 and that the intermediate integer calculation doesn't overflow.
