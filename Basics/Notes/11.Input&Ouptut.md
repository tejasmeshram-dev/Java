## 1. Scanner: Basic Input and Output

Java commonly uses Scanner for simple examples.
```
import java.util.Scanner;
public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int age = sc.nextInt();
        String name = sc.next();
        System.out.println(name);
        System.out.println(age);
        sc.close();
    }
}
```
Example input:
```
20
Zun
```
Output:
```
Zun
20
```

<br>

Important methods:

- `sc.nextInt();`
- `sc.nextLong();`
- `sc.nextDouble();`
- `sc.next();`
- `sc.nextLine();`
- `sc.nextBoolean();`

<br>

**One common issue: nextInt() leaves the line separator in the input stream. 
Calling nextLine() immediately afterward may consume the remainder of that line rather than the next full line.**

Example:
```
int age = sc.nextInt();
sc.nextLine(); // Consume the remaining newline
String name = sc.nextLine();
```
For competitive programming, BufferedReader is often useful for faster input.

<br>

## 2.BufferedReader

BufferedReader is a Java class used to read text input efficiently. It is often preferred over 'Scanner' when reading large amounts of input, such as in competitive programming and DSA coding assessments.

Unlike Scanner, which provides methods such as `nextInt()` and `nextDouble()`, BufferedReader primarily reads input as **strings**. You must convert the input into the required data type yourself.

<br>

### A. Basic Syntax

```
import java.io.BufferedReader;
import java.io.InputStreamReader;
import java.io.IOException;
public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(
            new InputStreamReader(System.in)
        );
        String name = br.readLine();
        System.out.println(name);
    }
}
```
Input: ` Zun `
Output: ` Zun `

<br>

### B. Understanding the Components

```
BufferedReader br = new BufferedReader(
    new InputStreamReader(System.in)
);
```

<br>

Each component has a specific purpose:

- `System.in`: Receives input from the keyboard or standard input.
- `InputStreamReader`: Converts the incoming byte stream into characters.
- `BufferedReader`: Buffers the characters and provides efficient text-reading methods.
- `br`: The variable used to access the `BufferedReader` methods.

**Remember:** You generally use `BufferedReader` together with `InputStreamReader` when reading standard input.

<br>

### C. Method: `readLine()`

` String input = br.readLine(); `
- `readLine()` reads an entire line of input and returns it as a `String`.

<br>

Example:
```
String name = br.readLine();
int age = Integer.parseInt(br.readLine());
System.out.println(name);
System.out.println(age);
```
Input:
        ```
        Zun
        20
        ```
Output:
        ```
        Zun
        20
        ```

- Notice that `readLine()` returns a `String` even when the input represents a number.
- Therefore, you must convert the string into the appropriate data type.

<br>

### D. Converting Input into Different Data Types

Since `BufferedReader` reads text, use Java's parsing methods to convert that text into numbers and other data types.

<br>

| Required data type | Conversion method        | Example                                            |
| ------------------ | ------------------------ | -------------------------------------------------- |
| `int`              | `Integer.parseInt()`     | `int n = Integer.parseInt(br.readLine());`         |
| `long`             | `Long.parseLong()`       | `long n = Long.parseLong(br.readLine());`          |
| `double`           | `Double.parseDouble()`   | `double x = Double.parseDouble(br.readLine());`    |
| `float`            | `Float.parseFloat()`     | `float x = Float.parseFloat(br.readLine());`       |
| `boolean`          | `Boolean.parseBoolean()` | `boolean b = Boolean.parseBoolean(br.readLine());` |
| `String`           | `readLine()`             | `String s = br.readLine();`                        |

<br>

Example:

```
int age = Integer.parseInt(br.readLine());
long population = Long.parseLong(br.readLine());
double price = Double.parseDouble(br.readLine());
```

**Important:** Parsing a string that does not represent a valid value of the required type can throw a `NumberFormatException`. For example:
```
int age = Integer.parseInt("20");  // Valid
int num = Integer.parseInt("abc"); // Throws NumberFormatException
```

<br>

### E. Reading Multiple Values from One Line

Suppose the input is: ` 10 20 30 `

With `Scanner`, you could write: 
```
int a = sc.nextInt();
int b = sc.nextInt();
int c = sc.nextInt();
```

<br>

With `BufferedReader`, `readLine()` reads the entire line as one string.

` String line = br.readLine(); `

The value of `line` is `"10 20 30"`, not three separate integers.

<br>

To separate the values, use `split()`.

```
String[] parts = br.readLine().split(" ");
int a = Integer.parseInt(parts[0]);
int b = Integer.parseInt(parts[1]);
int c = Integer.parseInt(parts[2]);
System.out.println(a + b + c);
```

Input: ` 10 20 30 `

Output: ` 60 `

<br>

Here is what happens:

1. `readLine()` reads `"10 20 30"`.
2. `split(" ")` separates the string into `["10", "20", "30"]`.
3. `parts[0]`, `parts[1]`, and `parts[2]` access the individual strings.
4. `Integer.parseInt()` converts each string into an integer.
5. The integers are added together.

**Practical tip:** For input separated by arbitrary whitespace, prefer `split("\\s+")` over `split(" ")`.

` String[] parts = br.readLine().trim().split("\\s+"); ` This handles multiple spaces and tabs more reliably. The `trim()` removes leading and trailing whitespace.

<br>

### F. Reading an Array of Integers

Reading arrays is one of the most useful applications of `BufferedReader` in DSA. 

Suppose the input is:
```
5
10 20 30 40 50
```

The first line contains the array size, and the second line contains the elements.

```
import java.io.BufferedReader;
import java.io.InputStreamReader;
import java.io.IOException;
public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(
            new InputStreamReader(System.in)
        );
        int n = Integer.parseInt(br.readLine());
        int[] nums = new int[n];
        String[] parts = br.readLine().trim().split("\\s+");
        for (int i = 0; i < n; i++) {
            nums[i] = Integer.parseInt(parts[i]);
        }
        for (int num : nums) {
            System.out.print(num + " ");
        }
    }
}
```

Output: ` 10 20 30 40 50 `

This is an important pattern to understand because many coding problems provide the array size on one line and the array elements on the next.

<br>

### G. What Does `throws IOException` Mean?

You may have noticed this in the examples:

` public static void main(String[] args) throws IOException `

BufferedReader's `readLine()` can throw an `IOException` if an input/output error occurs.

Java requires you to handle this checked exception or declare that the method can throw it.

One straightforward approach is: ` public static void main(String[] args) throws IOException ` . This declares that `main()` may pass the exception to the Java runtime.

Another approach is to use `try-catch`:
`
try {
    String input = br.readLine();
} catch (IOException e) {
    System.out.println("Input error occurred.");
}
`
For simple DSA and competitive programming solutions, using `throws IOException` in `main()` is common and convenient.

<br>

### H. Closing BufferedReader

You can close the reader using: ` br.close(); `

Closing it releases its associated resources. However, closing a `BufferedReader` that wraps `System.in` also closes the underlying standard input stream. For short, standalone coding-assessment programs, closing it at the end is generally fine. You do not need to close it immediately after reading if you still need to accept more input.

<br>

### I. Scanner vs. BufferedReader

| Feature                  | Scanner                             | BufferedReader                          |
| ------------------------ | ----------------------------------- | --------------------------------------- |
| Main input method        | `nextInt()`, `next()`, `nextLine()` | `readLine()`                            |
| Reads integers directly  | Yes, with `nextInt()`               | No; conversion is required              |
| Reads an entire line     | `nextLine()`                        | `readLine()`                            |
| Convenient for beginners | Very convenient                     | Requires more manual processing         |
| Large input              | Generally slower                    | Generally faster                        |
| Splitting input manually | Usually unnecessary                 | Often necessary                         |
| Common use               | Small programs and simple input     | Large input and competitive programming |

**Which should you use?**

- Use `Scanner` when you want convenient input handling and are learning Java fundamentals.
- Use `BufferedReader` when you need to read large amounts of input efficiently or want to practise common competitive-programming input patterns.

<br>

### J. Important Methods to Remember

| Method                    | Meaning                                                  |
| ------------------------- | -------------------------------------------------------- |
| `br.readLine()`           | Reads an entire line and returns it as a string.         |
| `Integer.parseInt(str)`   | Converts a string to an `int`.                           |
| `Long.parseLong(str)`     | Converts a string to a `long`.                           |
| `Double.parseDouble(str)` | Converts a string to a `double`.                         |
| `str.split("\\s+")`       | Splits a string using one or more whitespace characters. |
| `br.close()`              | Closes the reader and its underlying input stream.       |

- **Remember that `readLine()` returns `null` if the end of the input is reached before another line can be read.**
