## Operators

**Operators allow you to perform calculations, compare values, and combine conditions.**

### 1. Arithmetic operators

|Operator	|Meaning	|Example    |
|----    |----    |----    |
|+	|Addition	|5 + 2 → 7    |
|-	|Subtraction	|5 - 2 → 3    |
|*	|Multiplication	|5 * 2 → 10    |
|/	|Division	|5 / 2 → 2    |
|%	|Remainder	|5 % 2 → 1    |


Example: determine whether a number is even.
```
int n = 8;
if (n % 2 == 0) {
    System.out.println("Even");
} else {
    System.out.println("Odd");
}
```
Output: `Even`

Logic: An integer has remainder zero when divided by two if it is even.

<br>

### 2. Comparison operators

|Operator	|Meaning    |
|----    |----    |
|==	|Equal to    |
|!=	|Not equal to    |
|>	|Greater than    |
|<	|Less than    |
|>=	|Greater than or equal to    |
|<=	|Less than or equal to    |

Example:
```
int age = 20;
System.out.println(age >= 18);
```
Output: `true`

Note: Comparison expressions generally produce a boolean result.

<br>

### 3. Logical operators

|Operator	|Name    |Meaning    |
|----    |----    |----    |
|&&	|Logical AND    |Both must be true for true    |
|'||' |Logical OR    |At least one must be true for true    |
|!	|Logical NOT    |Turns true into false and vice versa    |

Example:
```
int age = 20;
boolean hasID = true;
if (age >= 18 && hasID) {
    System.out.println("Allowed");
}
```
Output: `Allowed`


**Short-circuit evaluation**

Java uses short-circuit evaluation for these operators to maximize performance and prevent unnecessary processing:
- && Short-Circuit: If the left side is false, the whole expression cannot possibly be true. Java skips evaluating the right side entirely.
- || Short-Circuit: If the left side is true, the whole expression is guaranteed to be true. Java skips evaluating the right side

Consider:
```
String s = null;
if (s != null && s.length() > 0) {
    System.out.println("Not empty");
}
```
If s != null is false, Java does not evaluate s.length() > 0.

<br>

### 4. Increment and decrement
```
int x = 5;
x++;
System.out.println(x);
```
Output:  `6`

Likewise:
```
int x = 5;
x--;
System.out.println(x);
```
Output:  `4`

<br>

**Difference between prefix and postfix expressions:**

```
int x = 5;
System.out.println(x++);
System.out.println(x);
```
Output:
```
5
6
```
The postfix expression x++ evaluates to the old value and then increments x.

With prefix increment:
```
int x = 5;
System.out.println(++x);
```
Output:  `6`

<br>


### 5. Compound assignment
```
int x = 10;
x += 5;  // x = x + 5
x -= 2;  // x = x - 2
x *= 3;  // x = x * 3
x /= 2;  // x = x / 2
```
These operators are common in loops and calculations.
