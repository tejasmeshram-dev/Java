## Arrays

**They store a fixed number of elements of a single declared type.**

<br>

### 1. Declaring and initializing arrays

`int[] nums = {10, 20, 30};`

You can also declare an array and allocate its size separately.

`int[] nums = new int[5];` This creates an array with five elements.

For an int array, the initial values are all zero: `[0, 0, 0, 0, 0]`

Other primitive arrays receive their corresponding default values. Reference-type arrays initially contain null elements.

For example: `String[] names = new String[3];`

Conceptually: `[null, null, null]`

<br>

### 2. Accessing elements

```
int[] nums = {10, 20, 30};
System.out.println(nums[0]);
System.out.println(nums[1]);
System.out.println(nums[2]);
```
Output:
```
10
20
30
```

Array indices begin at zero.

For an array of length n, valid indices range from: `0 to n - 1`

<br> 

### 3. Updating elements

```
int[] nums = {10, 20, 30};
nums[1] = 99;
System.out.println(nums[1]);
```
Output:  `99`

The array becomes: `[10, 99, 30]`

<br>

### 4. Array length
```
int[] nums = {10, 20, 30};
System.out.println(nums.length);
```

Output: `3`

<br>

**Notice the distinction:**

- For arrays:  `nums.length` , for arrays, length is a field.
- For strings:  `s.length()`
- For collection objects such as ArrayList:  `list.size()`

<br>

### 5. Summing array elements

```
public static int sumArray(int[] nums) {
    int sum = 0;
    for (int num : nums) {
        sum += num;
    }
    return sum;
}
```

For:  `int[] nums = {10, 20, 30};`

The result is:  `60`

Time complexity: `O(n).`

Extra space complexity: `O(1)`, excluding the input array.

<br>

### 6. Finding the largest element

```
public static int findMax(int[] nums) {
    int max = nums[0];
    for (int i = 1; i < nums.length; i++) {
        if (nums[i] > max) {
            max = nums[i];
        }
    }
    return max;
}
```
Example:
```
int[] nums = {-5, -2, -10, -1};
System.out.println(findMax(nums));
```
Output:  `-1`

- Why initialize max with nums[0] rather than zero?
    - Because the array could contain only negative numbers.
    - This is an important algorithmic habit: initialize variables according to the problem's actual constraints.

<br>

### 7. Reversing an array

```
public static void reverse(int[] nums) {
    int left = 0;
    int right = nums.length - 1;
    while (left < right) {
        int temp = nums[left];
        nums[left] = nums[right];
        nums[right] = temp;
        left++;
        right--;
    }
}
```
Example:  
```
int[] nums = {1, 2, 3, 4, 5};
reverse(nums);
System.out.println(Arrays.toString(nums));
```
Output:  `[5, 4, 3, 2, 1]`

This example introduces a common DSA technique: the two-pointer approach.
You must import Arrays to use `Arrays.toString()` in a standalone Java file: `import java.util.Arrays;`
