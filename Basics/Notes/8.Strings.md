## Strings

**Strings are especially important because many problems involve character manipulation, substrings, frequency counting, and two-pointer techniques.**

<br>

### 1. Creating strings

Strings use double quotation marks.
```
String s = "hello";
String a = "hello";
String b = "world";
```
You can concatenate strings using +:
```
String result = a + " " + b;
System.out.println(result);
```
Output: `hello world`

<br>

### 2. Important string methods

Suppose: `String s = "hello";`

|Method    	|Purpose	|Example - Result    |
|----   |----  |----   |
|s.length()	    |Returns the string length    |	5    |
|s.charAt(0)	|Returns a character at an index   	|'h'    |
|s.substring(1)	    |Returns the substring from index 1	    |"ello"    |
|s.substring(1, 4)	    |Returns indices 1 through 3	|"ell"    |
|s.equals("hello")	    |Compares string contents	 |true    |
|s.isEmpty()	    |Checks whether length is zero	 |false    |
|s.toCharArray()	|Produces a character array	   |['h','e','l','l','o']    |
|s.indexOf('l')	    |Finds the first occurrence	  |2    |
|s.contains("ell")	    |Checks for a substring	  |true    |
|s.toLowerCase()	|Converts letters to lowercase	  |"hello"    |
|s.toUpperCase()	|Converts letters to uppercase	  |"HELLO"    |
|s.trim()	|Removes leading and trailing characters at or below U+0020	"hello" for |" hello "|

**For modern Java, strip() is also useful because it handles Unicode whitespace more comprehensively than trim().**

<br>

**Important: substring() boundaries**
```
String s = "hello";
System.out.println(s.substring(1, 4));
```
Output: `ell`

The starting index is inclusive, while the ending index is exclusive.

This means: `s.substring(start, end)` contains characters at indices: start through end - 1

This convention matches many array and range operations in Java.

<br>

### 3. Strings are immutable

Consider:
```
String s = "hello";
s.toUpperCase();
System.out.println(s);
```
Output:  `hello`

- Why?
    - toUpperCase() returns a new string. It does not modify the original string.

Correct:
```
String s = "hello";
s = s.toUpperCase();
System.out.println(s);
```
Output:  `HELLO`

<br>

**Strings are immutable, which means their contents cannot be modified after the string object is created.**

**Changing one character**

This is invalid: `s.charAt(0) = 'H`

Instead, use a character array:
```
String s = "hello";
char[] chars = s.toCharArray();
chars[0] = 'H';
String result = new String(chars);
System.out.println(result);
```
Output: `Hello`

<br>

### 4. == vs .equals()

Consider:
```
String a = new String("hello");
String b = new String("hello");
System.out.println(a == b);
System.out.println(a.equals(b));
```
Output:
```
false
true
```
- Why?
    - == checks whether the references point to the same object.
    - .equals() checks whether the string contents are equal.

- For string content comparisons, generally use: `a.equals(b)`

- You can also use: `a.equalsIgnoreCase(b)` when you want to ignore differences in letter case.

<br>

- What about String a = "hello" and String b = "hello"?
    - Java can reuse the same interned string literal.
    - Consequently:
          ```
          String a = "hello";
          String b = "hello";
          System.out.println(a == b);
          ```
      may print: `true`
    - But that is not a reason to use == for content comparison.
    - Use .equals().
 
<br>

### 5. Comparing characters
```
char ch = 'a';
if (ch >= 'a' && ch <= 'z') {
    System.out.println("Lowercase English letter");
}
```
Output: ``Lowercase English letter`

<br>

**Useful Character Methods** :

- `Character.isLetter(ch);`
- `Character.isDigit(ch);`
- `Character.isWhitespace(ch);`
- `Character.isUpperCase(ch);`
- `Character.isLowerCase(ch);`
- `Character.toLowerCase(ch);`
- `Character.toUpperCase(ch);`

Example:
```
char ch = '7';
System.out.println(Character.isDigit(ch));
```
Output:  `true`

<br>

### 6. Building strings efficiently

For simple concatenation: `String fullName = firstName + " " + lastName;` This is perfectly fine.

But when repeatedly building a string inside a loop, use `StringBuilder`:
```
   StringBuilder sb = new StringBuilder();
   for (int i = 0; i < 5; i++) {
       sb.append(i);
   }
   String result = sb.toString();
   System.out.println(result);
```
Output: `01234`
StringBuilder is mutable, so you can change its contents without creating a new string object for every append.

<br>

**Useful Methods **:

- `sb.append("hello");`
- `sb.append('a');`
- `sb.append(123);`
- `sb.length();`
- `sb.charAt(0);`
- `sb.reverse();`
- `sb.toString();`
