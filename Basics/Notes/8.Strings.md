## Strings

**Strings are especially important because many problems involve character manipulation, substrings, frequency counting, and two-pointer techniques.**

<br>

### 1. Creating strings

Strings use double quotation marks.
```
String s = "hello";
String a = "hello";
String b = "world";
```
You can concatenate strings using +:
```
String result = a + " " + b;
System.out.println(result);
```
Output: `hello world`

<br>

Suppose: `String s = "hello";` `String b = "Hello"`

|Method    	|Purpose	|Example - Result    |

<br>

**Important: substring() boundaries**
```
String s = "hello";
System.out.println(s.substring(1, 4));
```
Output: `ell`

The starting index is inclusive, while the ending index is exclusive.

This means: `s.substring(start, end)` contains characters at indices: start through end - 1

This convention matches many array and range operations in Java.

### 3. Strings are immutable

Consider:
```
String s = "hello";
s.toUpperCase();
System.out.println(s);
```
Output:  `hello`

- Why?
    - toUpperCase() returns a new string. It does not modify the original string.

Correct:
```
String s = "hello";
s = s.toUpperCase();
System.out.println(s);
```
Output:  `HELLO`

<br>

**Strings are immutable, which means their contents cannot be modified after the string object is created.**

**Changing one character**

This is invalid: `s.charAt(0) = 'H'

Instead, use a character array:
```
String s = "hello";
char[] chars = s.toCharArray();
chars[0] = 'H';
String result = new String(chars);
System.out.println(result);
```
Output: `Hello`

<br>

### 4. == vs .equals()

Consider:
```
String a = new String("hello");
String b = new String("hello");
System.out.println(a == b);
System.out.println(a.equals(b));
```
Output:
```
false
true
```
- Why?
    - == checks whether the references point to the same object.
    - .equals() checks whether the string contents are equal.

- For string content comparisons, generally use: `a.equals(b)`

- You can also use: `a.equalsIgnoreCase(b)` when you want to ignore differences in letter case.

<br>

- What about String a = "hello" and String b = "hello"?
    - Java can reuse the same interned string literal.
    - Consequently:
          ```
          String a = "hello";
          String b = "hello";
          System.out.println(a == b);
          ```
      may print: `true`
    - But that is not a reason to use == for content comparison.
    - Use .equals().

### 5. Comparing characters
```
char ch = 'a';
if (ch >= 'a' && ch <= 'z') {
    System.out.println("Lowercase English letter");
}
```
Output: ``Lowercase English letter`

### 6. Building strings efficiently

StringBuilder is a Java class that allows you to modify a string without creating a new string object every time you make a change.

For simple concatenation: `String fullName = firstName + " " + lastName;` This is perfectly fine. But when repeatedly building a string inside a loop, use `StringBuilder`

<br>

**Useful Methods**

<br>

a. sb.append("hello") 

- Appends a string
- append() modifies the existing StringBuilder and returns the same StringBuilder object, allowing you to chain calls.
```
StringBuilder sb = new StringBuilder("Hello");
sb.append(" ");
sb.append("World");
sb.append("!");
System.out.println(sb);
```
Output: `Hello World!`

<br>

b. sb.append('x') 

- Adds a single character to the end of the StringBuilder. Notice that 'a' uses single quotes because it is a char.
```
StringBuilder sb = new StringBuilder();
sb.append('J');
sb.append('a');
sb.append('v');
sb.append('a');
System.out.println(sb);
```
Output : `Java`

**Note:** `sb.append("a");  // Appends a String` and `sb.append('a');  // Appends a char`

Both produce the same visible result in this example, but their argument types differ.
            
When constructing a string character by character, you will frequently use: `sb.append(ch);`
           
For example, when reversing a string or building a result from selected characters.

<br>

c. sb.append(123)

- Appends a number to the end of the StringBuilder. Java converts the number to its textual representation before appending it.
```
StringBuilder sb = new StringBuilder();
sb.append(10);
sb.append(20);
sb.append(30);
System.out.println(sb);
```
Output: `1020301`
The output is not `60` because it appends the numbers as in their text form, like "10" + "20" + "30" = "102030"

**IMP:** append() supports many data types, including String, char, int, long, double, and boolean.
```
StringBuilder sb = new StringBuilder();
sb.append('A');
sb.append(123);
sb.append('B');
System.out.println(sb);
```
Output: `A123B`

<br>

d. sb.length()

- Returns the number of characters currently stored in the StringBuilder.
```
StringBuilder sb = new StringBuilder("Hello");
System.out.println(sb.length());
```
Output: `5`
```
StringBuilder sb = new StringBuilder("Hi");
sb.append(" Java");
System.out.println(sb.length());
```
Output: `7` since its "Hi Java" completely
```
StringBuilder sb = new StringBuilder();
System.out.println(sb.length());
```
Output: `0`

<br>

e. sb.charAt(0) and sb.setCharAt(0, 'L')

- Returns the character at the specified index. Java uses zero-based indexing, meaning the first character is at index 0.
```
StringBuilder sb = new StringBuilder("Java");
System.out.println(sb.charAt(0));
```
Output: `J`
```
StringBuilder sb = new StringBuilder("Java");
sb.setCharAt(0, 'L');
System.out.println(sb);
```
Output: `Lava`

<br>

f. sb.reverse()

- Reverses the characters in the existing StringBuilder.
```
StringBuilder sb = new StringBuilder("12345");
sb.reverse();
System.out.println(sb);
```
Output: `54321`
```
String str = "Java";
StringBuilder sb = new StringBuilder(str);
sb.reverse();
String reversed = sb.toString(); 
System.out.println(reversed);
```
Output: `avaJ` 
It first reverses the content of the 'sb' and then converts the resulting StringBuilder into a String.
A StringBuilder cannot be returned where a String is required.

<br>

g. sb.toString()

- Converts the contents of a StringBuilder into a String.
```
StringBuilder sb = new StringBuilder();
sb.append("Java");
sb.append(" ");
sb.append("DSA");
String result = sb.toString();
System.out.println(result);
```
Output: `Java DSA`
