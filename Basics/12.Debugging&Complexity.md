int age = sc.nextInt();
sc.nextLine(); // Consume the remaining newline

String name = sc.nextLine();

For competitive programming, BufferedReader is often useful for faster input, but you do not need to master it on Day 1.

PART 13 — Basic Debugging and Complexity

These are not strictly Java syntax topics, but they are essential to learning DSA effectively.

13.1 Three kinds of errors
Compilation error
int x = "hello";

An incompatible type is assigned to an integer variable.

The compiler rejects the program.

Runtime error
int[] nums = {1, 2, 3};

System.out.println(nums[3]);

The code can compile, but execution throws an ArrayIndexOutOfBoundsException.

Logical error
int a = 5;
int b = 2;

double result = a / b;

System.out.println(result);

Output:

2.0

The code compiles and executes, but the result is incorrect if you intended decimal division.

Logical errors are especially common in DSA.

13.2 Basic time complexity

You do not need to master Big-O today, but you should begin recognizing the basic patterns.

O(1): Constant time

int x = nums[0];

Accessing a particular array element takes constant time.

O(n): Linear time

for (int num : nums) {
    System.out.println(num);
}

The work grows approximately in proportion to the number of elements.

O(n²): Quadratic time

for (int i = 0; i < nums.length; i++) {
    for (int j = 0; j < nums.length; j++) {
        System.out.println(nums[i] + nums[j]);
    }
}

For an array of length n, the inner operation executes n × n times.

Recognizing these patterns will become increasingly important as you solve NeetCode problems.
