Basic Input and Output

LeetCode usually handles input for you, so you rarely need to read standard input when submitting a solution.

However, standalone programs often need input.

Java commonly uses Scanner for simple examples.

import java.util.Scanner;

public class Main {

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        int age = sc.nextInt();
        String name = sc.next();

        System.out.println(name);
        System.out.println(age);

        sc.close();
    }
}

Example input:

20
Zun

Output:

Zun
20

Important methods:

sc.nextInt();
sc.nextLong();
sc.nextDouble();
sc.next();
sc.nextLine();
sc.nextBoolean();

One common issue: nextInt() leaves the line separator in the input stream. Calling nextLine() immediately afterward may consume the remainder of that line rather than the next full line.

Example:

int age = sc.nextInt();
sc.nextLine(); // Consume the remaining newline

String name = sc.nextLine();

For competitive programming, BufferedReader is often useful for faster input, but you do not need to master it on Day 1.
