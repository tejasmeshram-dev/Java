Methods

Methods are one of today's highest priorities.

If you understand methods properly, LeetCode's Java format becomes much easier.

7.1 What is a method?

A method is a named block of code that performs an operation. It can accept inputs and return a result.

Example:

public static int add(int a, int b) {
    return a + b;
}

Let's examine the structure.

Component	Explanation
public	Access modifier
static	Allows invocation without an instance of the declaring class
int	Return type
add	Method name
int a, int b	Parameters
return a + b;	Returns the result

The return type must be compatible with the returned value.

For example:

public static boolean isEven(int n) {
    return n % 2 == 0;
}

This method returns a boolean.

7.2 Calling a method

A method definition does not automatically execute its body.

You must call it.

public class Main {

    public static int add(int a, int b) {
        return a + b;
    }

    public static void main(String[] args) {
        int result = add(10, 20);

        System.out.println(result);
    }
}

Output:

30

Here:

add(10, 20)

passes two arguments into the method.

Inside the method:

a = 10
b = 20

Then:

return a + b;

returns 30.

Parameters vs. arguments

In this method:

public static int add(int a, int b)

a and b are parameters.

In this call:

add(10, 20)

10 and 20 are arguments.

7.3 The return statement

Consider:

public static int square(int n) {
    return n * n;
}

The method returns the result to the caller.

You can use it directly:

System.out.println(square(5));

Output:

25

Or store it:

int result = square(5);
return vs. System.out.println()

These are different operations.

public static int square(int n) {
    return n * n;
}

This produces a value that the caller can use.

By contrast:

public static void printSquare(int n) {
    System.out.println(n * n);
}

This prints a value but does not return it.

A void method cannot return a value using an ordinary return value; statement.

This is an important distinction for LeetCode.

If the expected signature is:

public int maxSubArray(int[] nums)

your method must return an integer.

Printing the answer is not enough.

7.4 static vs. non-static methods

For now, understand the practical distinction.

A static method belongs to the class rather than an individual instance.

public static int add(int a, int b) {
    return a + b;
}

You can call it from main() like this:

int result = add(2, 3);

A non-static method is associated with an object.

public int multiply(int a, int b) {
    return a * b;
}

You can invoke it using an instance:

Main obj = new Main();

int result = obj.multiply(2, 3);

Do not worry about mastering object-oriented programming today. Just understand why some methods use static and others do not.

7.5 Methods and arrays

This is where things start becoming useful for DSA.

public static int findMax(int[] nums) {
    int max = nums[0];

    for (int num : nums) {
        if (num > max) {
            max = num;
        }
    }

    return max;
}

Call it like this:

int[] nums = {4, 9, 2, 15, 7};

int result = findMax(nums);

System.out.println(result);

Output:

15

This method:

Receives an array.
Initializes the maximum to the first element.
Examines every element.
Updates the maximum when necessary.
Returns the answer.

Its time complexity is O(n), where n is the array length, because it traverses the array once.

Important assumption: The array must contain at least one element. Empty arrays require separate handling.

7.6 How LeetCode uses methods

A typical LeetCode solution looks like this:

class Solution {

    public int containsDuplicate(int[] nums) {
        // Your solution
        return false;
    }
}

This is an example of the expected structure, not a working implementation of the problem.

LeetCode generally creates the Solution object and invokes the method for you.

That means you usually do not need to write:

public static void main(String[] args)

for your submission.

You implement the required method using the exact signature expected by the problem.

For instance:

class Solution {

    public int maxSubArray(int[] nums) {
        int maxSum = nums[0];
        int currentSum = nums[0];

        for (int i = 1; i < nums.length; i++) {
            currentSum = Math.max(nums[i], currentSum + nums[i]);
            maxSum = Math.max(maxSum, currentSum);
        }

        return maxSum;
    }
}

This is a working implementation of maximum subarray sum using Kadane's algorithm.

You do not need to master the algorithm today. Focus on understanding the Java syntax.

Pay attention to:

The Solution class.
The method declaration.
The int[] nums parameter.
The local variables.
The loop.
The Math.max() calls.
The returned result.

This is the kind of code you should gradually become comfortable reading and writing.
