## Methods 

### 1. Definition

**A method is a named block of code that performs an operation. It can accept inputs and return a result.**

Example:
```
public static int add(int a, int b) {
    return a + b;
}
```

- public:	Access modifier
- static:	Allows invocation without an instance of the declaring class
- int:	 Return type
- add:	 Method name
- int a, int b:   Parameters
- return a + b; :	Returns the result

**note: The return type must be compatible with the returned value.**

For example:
```
public static boolean isEven(int n) {
    return n % 2 == 0;
}
```
This method returns a boolean.

<br>

### 2. Calling a method

A method definition does not automatically execute its body. You must call it.
```
public class Main {
    public static int add(int a, int b) {
        return a + b;
    }
    public static void main(String[] args) {
        int result = add(10, 20);
        System.out.println(result);
    }
}
```
Output: `30`

Here: `add(10, 20)` passes two arguments into the method.

Inside the method: `a = 10` & `b = 20`

Then: `return a + b;` returns 30.

<br>

**Parameters vs. Arguments**

In this method: `public static int add(int a, int b)` a and b are parameters.

In this call: `add(10, 20)` 10 and 20 are arguments.

<br>

### 3. The return statement

**A. This produces a value that the caller can use. It returns the result to the caller.**
```
public static int square(int n) {
    return n * n;
}
```

<br>

**B. You can use it directly:**

`System.out.println(square(5));`

Output: `25`

<br>

**C. Or store it:**
```
int result = square(5);
return vs. System.out.println()
```

<br>

**By contrast:**
```
public static void printSquare(int n) {
    System.out.println(n * n);
}
```
This prints a value but does not return it.

A void method cannot return a value using an ordinary return value; statement.

If the expected signature is: `public int maxSubArray(int[] nums)` your method must return an integer. Printing the answer is not enough.

<br>

### 4. static vs. non-static methods

**A. Static method belongs to the class rather than an individual instance.**
```
public static int add(int a, int b) {
    return a + b;
}
```
You can call it from main() like this:  `int result = add(2, 3);`

<br>

**B. Non-static method is associated with an object.**
```
public int multiply(int a, int b) {
    return a * b;
}
```
You can invoke it using an instance:  
```
Main obj = new Main();
int result = obj.multiply(2, 3);
```

<br>

### 5. Methods and arrays
```
public static int findMax(int[] nums) {
    int max = nums[0];
    for (int num : nums) {
        if (num > max) {
            max = num;
        }
    }
    return max;
}
```
Call it like this:
```
int[] nums = {4, 9, 2, 15, 7};
int result = findMax(nums);
System.out.println(result);
```
Output: `15`

This method:

- Receives an array.
- Initializes the maximum to the first element.
- Examines every element.
- Updates the maximum when necessary.
- Returns the answer.

**Its time complexity is O(n), where n is the array length, because it traverses the array once.**
**Important assumption: The array must contain at least one element. Empty arrays require separate handling.**
